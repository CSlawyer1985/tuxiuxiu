# 图修修：第一次使用

图修修是活动照片批量处理 Skill，需要支持本地 Skill 的 AI 助手和本地运行环境。网站负责介绍与下载，修图在用户自己的电脑上完成。

## 1. 选包与检查电脑

- 普通包：含四模型，首次联网安装运行库；需要已有 Python 3.12—3.14。
- Apple 芯片离线包：含四模型及对应运行库，需 macOS、Apple 芯片（M系列）、已有 Python 3.14。
- 两包不含 Python 安装程序。当前实测为 Mac Apple 芯片、Python 3.14。Windows未适配；Linux、Intel Mac、其他 Python 版本没有在本轮实机验收。

没有 Python 时，先从 [Python 官方下载页](https://www.python.org/downloads/)准备受支持的版本，也可让助手先检查。本包不替换系统 Python。

## 2. 解压并准备一次

解压后保留完整 `event-photo-retouch` 文件夹。Mac可双击“一键准备.command”，阅读提示后输入 `y`。普通包首次安装需要联网；匹配的离线包从随包运行库准备。独立环境约400 MB，照片、无损母版与成品另需空间。

若系统因执行权限而无法双击，交给助手从该文件夹执行准备入口，不要求关闭系统安全设置。助手可按当前用户授权执行：

```bash
python3 <skill-root>/scripts/setup_runtime.py setup --yes
python3 <skill-root>/scripts/setup_runtime.py doctor
```

匹配离线包可加 `--offline`。只有实际自检返回 `ready=true`，且四模型均通过调用检查后，才认为模型环境准备完成。模型准备成功不等于每张照片效果通过。

## 3. 添加 Skill 并交给活动照片

本轮使用 Codex 完成本地流程。在 Codex 打开照片工作目录，把解压文件夹路径交给助手，明确要求：“将这个完整 Skill 安装到当前工作目录的 .agents/skills/event-photo-retouch，若已有同名目录先停下来核对，完成环境自检再修图。”随后以 $event-photo-retouch 调用；技能未出现时重启 Codex。[官方加载位置说明](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)。其他宿主先核对其本地Skill与脚本能力。

可以这样说：

> 使用图修修 Skill 处理这个活动照片文件夹。先给我比较样片，再由我确认效果和水印后批量处理。

同一场活动继续使用已有记录；新场景或新灯光条件补样。缺色彩标记时先由你决定是否允许按sRGB试修。原片保持，成品另存。

## 4. 看样、确认与继续批量

上方比较原片和修图效果；下方比较三版水印叠加。右侧先调方案和参数，再选水印素材。放大检查按窗口显示，需要原像素细节时在工作台相应细节区查看。修改参数后更新原尺寸样片，再确认。

远处小脸、遮挡或五官不可靠时，相关连续皮肤会暂缓磨皮并提示复核；可以保留可完成的调色。发现额头、耳颈、肩部等覆盖遗漏，先修范围，不能用更高磨皮强度掩盖分界。

首次成功后复用运行环境和选区缓存。拉动滑杆不会重新安装模型。换电脑需重新准备，不复制旧虚拟环境。
