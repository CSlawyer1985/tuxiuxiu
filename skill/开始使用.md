# 图修修：开始使用

本文件夹是可分享的Skill，已包含皮肤、头发、五官与人脸定位四个模型。模型和运行库只需准备一次，之后在本机复用，照片不上传。

1. 电脑需要已有Python3.12—3.14。当前实测为Mac Apple芯片、Python3.14；Windows尚未适配。缺少Python时准备入口会明确提示，不会修改系统Python。
2. Mac解压后双击“一键准备.command”，阅读提示并输入y开始。普通包第一次需要联网下载运行库；匹配平台的离线包已包含运行库。准备完成会显示实际推理自检结果。
3. 将整个`event-photo-retouch`文件夹添加到你使用的、支持本地Skill的AI助手中。也可把文件夹交给助手并明确要求安装此Skill、完成首次准备。
4. 把照片文件夹路径交给助手，例如：“使用图修修 Skill处理这个文件夹，先给我比较样片，再决定效果和水印。”

四个模型原始总计约21.1MB；普通压缩分享包约20MB。Mac Apple芯片／Python3.14离线包只能用于对应环境，不包含Python安装程序。准备好的独立环境约400MB，不安装到系统Python；换电脑后重新准备，不复制旧虚拟环境。

四模型自动完成初选和细化，分别记录肤色与磨皮范围。远处小脸或五官不可靠时，暂缓该处连续皮肤的磨皮并提示复核，避免沿人脸框产生分界；调色可继续。发际线、五官和衣物误选仍需核对；模型安装成功不等于每张照片质量都已通过。原片保留，先看样片，再由你确认修图方向及水印。

Linux或由助手操作时，具体命令、模型校验和环境检查见[分享安装说明](references/分享安装与皮肤模型.md)。
