# 图修修：活动照片批量处理

读取 [修图业务规则](references/修图业务规则.md)，按用户已有活动信息、样片和水印确认范围继续工作。新活动或独立批次先分析原片、选代表性照片，再比较适合本批的方案与强度；既往偏好不成为跨批默认。同批追加只对未覆盖条件补样，不重复已确认信息。

照片使用本地非生成式像素工具；不改变人物身份、构图与现场事实。生成工具仅可独立制作新水印资产，不能接收照片作为重绘或试修输入。

磨皮前必须逐图核对全部可见皮肤及排除区，重点检查额头到发际线、耳、面颈、肩胸和手臂手部；不能把自动人脸椭圆或颜色候选直接当完整磨皮范围。覆盖、五官保护、连续过渡和原像素纹理四项未通过时，程序暂停该图磨皮，保留可完成的调色。发现遗漏后从原片修正选区并重出样，不能只提高强度掩盖分界。详细门槛见下列规范与参数闭环。

按当前任务读取：

- 首次使用、分享、依赖缺失或启用语义皮肤候选：按 [分享安装与皮肤模型](references/分享安装与皮肤模型.md) 准备独立环境并运行实际推理自检，后续用该环境启动流程。分享包随附四个已注明来源和许可的模型，准备成功不等于照片质量通过。语义模式自动提取原像素局部，分别保存肤色与纹理候选，并标记异常范围，详见安装说明。

- 基础调色、混合光、肤色和质感处理：[完整执行规范](references/基础调色与肤色精修规范.md) 与 [过程记录模板](references/基础调色与肤色精修_记录模板.json)。模板复制到活动的 `scratch/` 填写。
- 工具选择、预设兼容、蒙版、样片确认、续跑或交付：[执行契约](references/执行契约与兼容性.md)。需要机器校验时使用 [批次绑定模板](references/批次绑定模板.json)。
- 自动批量、网页比较／选区编辑、人作决定和对话回传：[管线使用与实际边界](references/自动批量管线与网页选样.md)。优先使用已打包的本地流程；同活动继续，不重建任务。
- 新活动需水印却没有成品素材时，按 [三版水印与网页选择](references/三版水印与网页选择.md) 直接制作纯文字无 Logo、带 Logo／主题标志、自由设计三版。中间上方始终保留原片与修图效果的核心对比，下方并排展示当前同一张照片叠加三版水印的预览，点击可放大；不得用水印对比替代修图主预览。右侧修片方案与参数在上，独立水印素材选择在下，不放带照片的效果缩略图。同场已确认则复用，明确不加则跳过。
- 用户确认并完成导出后，按 [确认后归档与同场续跑](references/确认后归档与同场续跑.md) 保留已选方案完整链，将未选与过期试修移入废纸篓；原片、成品和真实确认不改，追加同场照片仍按确认范围继续。
- 用户说“不够亮／再自然一点／有瑕疵”、提交网页修改要求或需要暴露参数时，读取 [参数微调与修改闭环](references/参数微调与修改要求.md)。先将文字要求落实为当前范围的新样片，不能把留言当作旧效果批准；以原尺寸样片确认的参数继续批量。
- 能力检查或引入外部颜色资源：[处理能力与效果边界](references/处理能力与效果边界.md)。未知字段、复合链和未校准资源停用。

包内包含盘点、人工记录核验及传统像素批量管线；不自动批准真实照片：

```bash
python3 <skill-root>/scripts/photo_inventory.py <source-folder>
python3 <skill-root>/scripts/batch_contract.py --project <activity-folder> --record <batch-json>
python3 <skill-root>/scripts/setup_runtime.py run -- start --project <initialized-activity-folder>
```

传统管线需要Python3.10及以上，分享版锁定模型环境需要Python3.12—3.14。盘点／核验需Pillow，渲染还需NumPy；完整准备包含OpenCV与MediaPipe，macOS Vision为可选定位能力。支持macOS／Linux，离线wheel须匹配平台及Python版本；其他平台不冒称已验证。首次安装与下载按当前用户明确授权执行，之后复用；不上传原片或依赖另一台电脑路径。本包只附带已注明许可的官方皮肤模型，不附带专有厂商素材、私人人像、活动水印、账号或研究缓存。

用整图、统一分享尺寸与原像素面颈手部细节共同验收，分别记录数值自查、视觉复核、用户选择与正式交付状态。工具检查通过不代表照片效果通过，也不把方向性反馈自动升级为正式启用。
