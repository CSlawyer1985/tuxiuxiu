# 三版水印与网页选择

新活动需要水印、用户未提供成品水印且没有本场已确认版本时，助手直接制作三版，不先让用户在文字风格描述中反复挑选。活动名称等必要文字缺失时只补问缺项；已明确不加水印则跳过。同场确认后复用，不因追加照片或重新打开面板而再生成。

1. **无 Logo 版**：只用已确认的活动文字，注重字体与排版；“无 Logo”不是整张照片不加水印。
2. **有 Logo 版**：活动文字配图形标志。有用户提供的 Logo 时原样使用；否则设计原创主题图形，不冒充现有机构、主办方或官方标识。
3. **自由设计版**：在主题、图形、排版上形成实质区别；事实文字仍受用户资料约束，不编造日期、主办方等内容。

三版各自保存透明 RGBA PNG 至活动 `scratch/watermark/`，保留独立版本与校验值。助手调用当前可用生图工具独立设计水印，不把照片交给生图工具；纯文字与文字校正可用本地排版制作。没有可用生成工具时如实说明并完成可做的本地设计，不把未生成的版本称为已生成。文字逐字核对，检查实际非透明边界、三版区别及在照片上的可读性。

网页服务负责登记、展示和合成；它本身不调用模型自动生图。完整自动流程由读取本 Skill 的助手先制作资产，再注册至本活动网页。不得把三版通用模板当作任何活动的默认品牌标志。

## 预览区与选择栏的分工

- **中间上方始终保留修图主预览。** 原片与当前修图效果的对比是核心，保留原有的大图、前后分割对照、调色／微调结果、选区覆盖及原像素细节入口。有三版水印或已经选版时，该主预览也不能消失、被三版水印预览替代或缩成右侧小图。
- **三版水印对照放在主预览下方。** 当前同一张照片分别叠加三版水印，按候选顺序并排展示，并标明版本名称及选中状态。三张使用相同修片方案、已保存参数、构图、显示尺度与背景，只改变水印资产及其登记的排版参数；点击预览图或放大入口可检查对应版本，不能用三张不同照片代替三版对照。
- **水印放大检查适合弹窗。** 点击三版中的任意预览，弹窗默认按可用宽度与高度等比缩放，完整显示该张照片和对应水印；不按原片像素尺寸铺开，不裁切画面，不要求横向或纵向滚动才能看到水印。横图、竖图及窗口尺寸变化均重新适配，水印随照片保持同一比例和位置。原像素细节检查保留在修图主预览的独立入口，不与水印弹窗混用。
- **右侧栏选择水印素材。** 三个选项仅显示各自独立的透明 Logo／文字水印、名称与选中状态，可用中性或棋盘背景帮助看清透明边界；不得把带整张照片的叠加预览缩在右侧选项里，也不重复放一张已选水印大图。纯文字版仍保留为纯文字候选，不因布局调整强制改为图形 Logo。
- **右侧按修片在上、水印在下排列。** 先展示修片方案、应用范围、调色／微调参数和相关检查，再展示独立水印素材选择；最后保留补充说明及确认操作。不得把水印选项提前到修片方案与参数上方。右侧不另放带照片的微调小预览，所有照片效果、放大与原像素检查仍在中间进行。
- **切图与选版保持对应。** 切换照片时，中间三张预览同步为新选中的同一张照片，不回退展示其他代表照片。缺少当前照片的对应预览时明确显示待生成状态。选择水印后，在中间三版中突出选中项，并在其中更新可确认的原尺寸样片；选择栏与中间选中状态一致，其他候选保留供比较。变更修片方案或参数后，对照须对应同一版效果；快速预览与正式样片明确区分，不把旧参数的排版图冒充新效果。
- **保持主次和并排关系。** 三版水印预览始终位于修图主预览下方；小屏空间不足时在该区域横向滚动查看三个并排候选，不挤占或隐藏上方修图对比，也不把照片预览移回右侧。选择水印或打开、关闭水印对照不改变修图主预览的存在及核心地位。

布局验收至少核对：中间上方的大图修图对比在有／无水印、选版前后都保留；下方三个水印候选并排、可点击放大；右侧修片内容在上、水印选择在下且三个选项均为独立素材；中间三版绑定当前同一张照片及同一修片参数；切图与选版后图像和标记同步；新参数未生成时能看出待更新；仅选版不会导出。规则更新不等于面板已实现，实际界面改造需另外核对代码及运行画面。

## 登记与使用

先完成本批代表样片，再制作三版并写活动相对路径的清单，例如 `scratch/watermark/候选清单.json`：

```json
{
  "candidates": [
    {"id": "text-v1", "kind": "text_only", "label": "纯文字 · 无 Logo", "path": "scratch/watermark/text-v1.png", "width_fraction": 0.18, "margin_fraction": 0.025},
    {"id": "logo-v1", "kind": "with_logo", "label": "主题标志 · 有 Logo", "path": "scratch/watermark/logo-v1.png", "width_fraction": 0.18, "margin_fraction": 0.025},
    {"id": "free-v1", "kind": "creative", "label": "自由设计", "path": "scratch/watermark/free-v1.png", "width_fraction": 0.20, "margin_fraction": 0.025}
  ]
}
```

```bash
python3 <skill-root>/scripts/retouch_pipeline.py set-watermarks --project <activity-root> --manifest scratch/watermark/候选清单.json
```

登记会生成各版叠到代表照片上的排版预览，放在中间预览区作三版对照；右侧三版选项只展示各自水印资产，具体布局遵循上节。排版示意不替代原尺寸样片：用户选中一版后，流程重新生成含该水印的样片与原像素检查图，并在中间更新所选候选；更换版本使旧样片确认失效。最终“确认效果并开始批量”才授权照片导出，并将所选编号、资产校验值、比例及边距和完整修片参数一起保存／回传。单独点选水印不批准照片、不导出。

当前包内三版入口使用右下角排版；沿用用户已经确认的位置和比例。需要其他位置时先完成相应合成与预览能力，不把未实现的位置字段写成已生效。长主题按实际尺寸调整宽度和比例，当前接口限定短边宽度 5%—30%、边距 1%—8%，这些是实现边界，不是行业标准。

用户提供成品水印时使用该素材，不强制重做三版；已确认或已有成品的活动也不自动换版。网页允许明确取消使用水印。三版资产变更、跨活动候选、旧样片提交或所选版本不匹配均拒绝；历史交付不覆盖。照片内分割线直接拖动对比，支持键盘微调，不再另设照片下方重复滑条。
